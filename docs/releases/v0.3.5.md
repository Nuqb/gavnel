# Gavnel v0.3.5

- Clip inspection, timeline thumbnails, previews, audio mixing, and H.264/AAC exports now use Windows-native media services. The installer no longer bundles external editing executables or codec DLLs.
- Added native editor diagnostics and automated installation, update, and uninstall verification.
- Streamlined releases with one command, shared validation, optimized build caches, verified automatic publication, and recovery from interrupted publishing.
- Included the current source-available license and historical MIT notices. Previously granted MIT permissions and third-party licenses remain in effect, and users retain the rights to their recordings and screenshots.

The installer preserves settings and recordings. Windows 11 x64, SDR capture, and an NVIDIA GPU with compatible NVENC drivers are required for recording. Editor export uses Windows H.264/AAC encoding; no new recording or export performance claim is made in this release. The Windows installer is not Authenticode-signed.
