# Gavnel v0.3.11

- Deleting a clip from the Library now slides the remaining clips into place and shows a short "Clip deleted." confirmation. Deleted clips no longer briefly reappear, and they're removed from any montage selection.
- Revealing a clip in File Explorer now selects the file instead of just opening its folder.
- The editor preview now fills the available window height above the timeline, and editor errors appear above the preview where they're easier to see.

One x64 installer supports Windows 10 22H2 (build 19045) and Windows 11. Recording requires an SDR source and an NVIDIA GPU with compatible NVENC drivers. Game-only and selected-app audio require Windows 11. Settings and recordings are preserved during updates. The installer is not Authenticode-signed.
