Gavnel is a Windows gameplay recorder and replay clipper. Clips and recordings stay on your PC.

Download **Gavnel-Setup-0.3.0-x64.exe**, run it, and complete the guided setup. No Rust toolchain, separate FFmpeg installation, or administrator access is required.

### Requirements

- Windows 11 x64.
- An NVIDIA GPU with NVENC support and a compatible display driver.
- An SDR capture source. AMD/Intel GPU encoding and HDR capture are not supported.

### Included

- Replay clips, long recordings, bookmarks, screenshots, and customizable shortcuts.
- PC audio and optional microphone recording, with a reusable microphone test.
- Guided onboarding and localized interface.
- **Settings > General > Updates** checks this repository for new releases. Download an update there, then choose **Restart to update**. Gavnel finishes saving before the installer runs; recordings and preferences stay in their existing locations.

The installer is currently unsigned, so Windows may display an unknown-publisher or SmartScreen prompt. Download only from this repository; SHA256SUMS.txt is included for independent verification. There are no code-signing identity guarantees in this release.

Hardware examples in setup are advisory, not benchmarked minimums. Recording performance depends on the game, driver, GPU headroom, and storage.
