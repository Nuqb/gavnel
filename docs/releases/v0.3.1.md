# Gavnel v0.3.1

- Consistent onboarding-style checkboxes and radio buttons throughout the app.
- Improved recording mode sizing and spacing, with more compact settings panel headings.
- Cleaner settings and clip library, including a full-width, vertically centered search field.
- Custom games can be added in a dedicated dialog.
- Shortcut labels display punctuation as familiar symbols, and passive keyboard handling allows shortcuts to continue reaching other apps.
- Smoother toggle animations and improved source-launcher progress, with an optional shortcut for the latest completed build.
- Installed builds check for updates automatically.

Windows 11 x64, SDR capture, and an NVIDIA GPU with compatible NVENC drivers are required. AMD/Intel GPU encoding and HDR capture are not supported. This update does not claim recording performance improvements.

The installer preserves settings and recordings. The Windows installer is not Authenticode-signed.
