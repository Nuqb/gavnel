# Gavnel v0.3.7

- One x64 installer now accepts Windows 10 22H2 (build 19045) and Windows 11.
- Windows 10 can use PC audio, selected playback devices, and microphone capture. Game-only and selected-app audio require Windows 11 and are disabled when unavailable.
- Settings requesting unsupported application-audio capture produce a clear error before replacing an active recording. Gavnel does not silently switch to recording other applications' audio.
- Installer publisher and executable company metadata now show Software by Brox.

Windows 10 live recording validation is pending. Automated checks and a successful build do not establish full recording compatibility on Windows 10.

The installer preserves settings and recordings. Recording still requires an SDR source and an NVIDIA GPU with compatible NVENC drivers. No recording-performance improvement is claimed. The Windows installer is not Authenticode-signed.
