# Gavnel v0.3.4

- Screenshot saves now play a sound and show a confirmation banner when enabled.
- Screenshot capture and save failures now show an error banner when banners are enabled.
- General settings now groups feedback for screenshots and clips under Capture feedback, with Play sound, Show banner, volume, and a preview button.

The installer preserves settings and recordings. Windows 11 x64, SDR capture, and an NVIDIA GPU with compatible NVENC drivers are required. The Windows installer is not Authenticode-signed.
