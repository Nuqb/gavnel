# Gavnel v0.3.3

- Edit clips and long recordings with trimming, cropping, audio controls, project saving, and montage exports.
- Choose game or application audio and configure optional game highlights.
- Use separate clip and long-recording shortcut menus, including a bookmark shortcut.
- Play and pause from the video, return from the editor to the player, and use updated editor controls.
- Improved library, recording, and playback behavior.

The installer preserves settings and recordings. Windows 11 x64, SDR capture, and an NVIDIA GPU with compatible NVENC drivers are required. Highlight detection is experimental for supported games. The Windows installer is not Authenticode-signed.
