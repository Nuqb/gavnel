# Gavnel v0.3.8

- Clip-length selections in quick settings now stay applied after shortcut synchronization and settings reload. Quick settings and the toolbar share the same duration choices.
- Capture and clip-save errors now remain visible in Gavnel with Copy and Dismiss controls. Requesting a clip after capture fails retains the original failure details.
- Whole-screen capture on Windows 10 now uses desktop duplication to avoid the yellow system capture border. Individual-window capture may still show the Windows 10 capture border.

The reported clipping failure on another Windows 10 computer remains undiagnosed. This update improves error reporting and the desktop capture path; it does not claim that the machine-specific failure is resolved. Windows 10 live recording validation is still pending.

One x64 installer supports Windows 10 22H2 (build 19045) and Windows 11. Recording requires an SDR source and an NVIDIA GPU with compatible NVENC drivers. Game-only and selected-app audio require Windows 11. Settings and recordings are preserved during updates. The installer is not Authenticode-signed.
