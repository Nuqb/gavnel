# Gavnel v0.3.2

- Clicking Long recording in the top toolbar opens the same popup as Clip instead of starting a recording.
- Toolbar shortcuts show each key in its own box, including Alt and F7, without plus signs or a bullet separator.
- Removed the folder, microphone, capture, and save clip buttons from the Library toolbar.

The installer preserves settings and recordings. Windows 11 x64, SDR capture, and an NVIDIA GPU with compatible NVENC drivers are required. The Windows installer is not Authenticode-signed.
